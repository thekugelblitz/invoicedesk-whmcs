# Munshi Ji hosted source

The complete editable Sites source is in munshi-ji-sites-source.tar.gz. It includes the shared TanStack frontend, Worker API, D1 schema/migrations, R2 download handling, tests, lockfile and maintained Sites build scripts. No runtime secrets or customer records are included.

Live private dashboard: https://munshi-ji.hosting.chatgpt.site

The repository root is the cPanel PHP edition. Its prebuilt browser assets require no Node on cPanel. The hosted source uses the Sites workflow and API mode; direct SELECT-only MySQL remains available in the cPanel edition.
